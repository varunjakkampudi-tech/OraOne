# Risk Exceptions Register

This register records approved security risk exceptions for OraOne.

## Policy

Only the repository owner may approve an exception. Autonomous agents and contributors cannot approve risk exceptions. Every approved exception must include an explicit owner approval record, an expiration date, and documented evidence.
