# Product portfolio

This page separates repository evidence from product direction.

## Product 1 — OraOne AI Chat Platform

Status: active repository product.

Evidence includes multitenant website agents, knowledge ingestion and pgvector retrieval, authenticated and public chat APIs, lead workflows, integrations, billing primitives, a public widget loader, tenant administration, and webhook delivery.

Release readiness is not implied. Live Cognito, provider billing, external delivery, backup/restore, deployment, and cost-control evidence remain separate gates.

## Future concepts

These themes are product direction, not shipped commitments:

1. Multi-channel conversations beyond the current widget and API surfaces.
2. Deeper CRM, calendar, and third-party workflow automation.
3. Advanced analytics and organization intelligence.
4. Marketplace and reusable agent distribution.
5. Enterprise policy, compliance, and regional deployment options.

Do not present a roadmap item as generally available until it has implementation, tests, and an approved release note.
