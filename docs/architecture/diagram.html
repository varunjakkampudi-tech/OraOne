OraOne production architecture

Overview of the production stack at commit e69494d. Static drawing, not a live status view.

What each box does

  • Caddy terminates TLS, sets security headers, and routes /api/* to the backend. Everything else goes to the frontend.
  • Frontend serves the web app and the widget script. It calls the API on the same origin.
  • Backend API handles sign-in, tenants, channel webhooks, the widget API, retrieval-augmented answers, and admin routes.
  • Workers run scheduled workflows, wait resumption, the webhook outbox, and daily pruning of error records older than 30 days.
  • Migrate applies database migrations once before the API and workers start.
  • PostgreSQL stores tenants, conversations, knowledge chunks (pgvector), workflows, and audit records. Redis holds rate limits, idempotency keys, and short-lived codes.

Source of truth: docker-compose.prod.yml, Caddyfile, backend/server.py, backend/worker.py. Detail is in SYSTEM.md, DATA.md and DEPLOYMENT-DIAGRAM.md in this folder.
