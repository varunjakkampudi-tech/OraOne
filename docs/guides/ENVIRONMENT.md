# Environment configuration

The environment variables are documented in one place:
[operations/CONFIGURATION.md](../operations/CONFIGURATION.md). It lists each variable with its
default, whether it is required, and whether the admin console can change it.

Templates to copy from: [`backend/.env.example`](../../backend/.env.example) and
[`.env.example`](../../.env.example). Production settings are in
[HOSTINGER-DEPLOYMENT](../HOSTINGER-DEPLOYMENT.md) and [DEPLOYMENT](../operations/DEPLOYMENT.md).

Which AI model a plan allows is described in [PRODUCTS](PRODUCTS.md), section 6.
