# Feature Matrix

This matrix inventories every user-facing route in `src/routes`, detailing the backend endpoint(s) called, verification evidence, and implementation status per repository standards. No service is described as live or production-ready.

### Status Definitions

- **Built**: Code and passing test coverage exist in the repository for the feature.
- **Live-needs-account**: Code and tests exist, but live operation requires external identity, provider credentials, or mail server configuration.
- **NOT_ASSESSED**: Marked with an explicit reason where tests are absent, layout-only, or limited to shallow smoke tests without feature assertion.
